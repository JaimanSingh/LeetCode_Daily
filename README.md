# LeetCode Daily

My LeetCode solutions, organized into two collections.

## Repository structure

- **[Existing-Problems](Existing-Problems/)** — 29 solutions from before the NeetCode 150 organization, preserved as originally submitted (Python and C++).
- **[NeetCode-150](NeetCode-150/)** — solutions from my ongoing [NeetCode 150](https://neetcode.io/practice) practice, pushed using LeetPush.

## LeetPush setup for future submissions

1. Open the **LeetPush** browser extension settings.
2. Keep the GitHub repository set to `JaimanSingh/LeetCode_Daily`.
3. Set its **custom target directory** to `NeetCode-150` (without a leading slash) and save.
4. Push an accepted LeetCode submission and verify that the file appears inside `NeetCode-150/`.

**Note:** The upload directory is configured in the LeetPush extension, not in GitHub. GitHub folder creation alone cannot redirect submissions. LeetPush won't automatically verify whether a pushed problem is in the NeetCode 150 list.
