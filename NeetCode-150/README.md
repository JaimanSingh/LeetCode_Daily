# NeetCode 150

Solutions for the [NeetCode 150](https://neetcode.io/practice) roadmap will be collected here.

To push new solutions into this folder, open the LeetPush browser extension and set its **custom target directory** to `NeetCode-150`. Keep the repository set to `JaimanSingh/LeetCode_Daily`.

This folder is currently a starting point; future accepted submissions will appear here once the extension setting has been saved. LeetPush does not automatically filter out problems outside the NeetCode 150 list.
